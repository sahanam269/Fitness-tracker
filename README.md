# 🏃 Fitness Tracker

A web-based Fitness Tracker application developed using Flask, SQLite, HTML, CSS and JavaScript.

## Features

- Student registration and login
- Track fitness activities
- Store activity data using SQLite
- User-based activity tracking
- Mobile-friendly web interface
- Android APK version

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Android Studio
